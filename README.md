# Finger Counting Web App

MediaPipe Hands を活用した、**不要な視覚刺激を極限まで排除したミニマルな指カウント Web アプリケーション** です。  
カメラ映像を通常時は表示せず、画面上には大きな数字と丸印（インジケーター）のみを落ち着いたデザインで表示します。

---

## ✨ 主な特徴

- **不要な視覚刺激のないミニマルUI**:
  - 通常時はカメラ映像を完全に非表示。大きな数字と丸い印のみの落ち着いた画面で、集中を妨げません。
- **両手対応（0〜10 カウント）**:
  - 片手（0〜5）はもちろん、両手を同時に認識して最大10までカウントできます。
- **カウント方式の切り替え**:
  - **指を曲げてカウント（デフォルト）**: 手を開いたパーが0、指を折るごとに+1。
  - **指を立ててカウント**: 手を握ったグーが0、指を立てるごとに+1。
- **音声読み上げ（Web Speech API）**:
  - 本数が変わるたびに、クリアな日本語音声で数字をテンポよく読み上げます（ON/OFF切り替え可能）。
- **動作安定化スタビライザー（感度調整可能）**:
  - 手の角度変化や指の過渡期のブレによるチラつきを防止。
  - 確定までのフレーム数をスライダー（3〜25フレーム）でお好みに調整可能。
- **Special オプション（花火演出 & 爆発音）**:
  - 10から0までスムーズにカウントダウンできると、画面全体に所狭しと大輪の花火が打ち上がります。
  - Web Audio API によるリアルな重低音爆発音（ドォーーン！）付き。
- **開発者デバッグモード**:
  - カメラ映像や手の骨格（ランドマーク）、指ごとの判定状況を小窓で確認可能。

---

## 🛠️ 技術スタック

- **フロントエンド**: HTML5, CSS3, Vanilla JavaScript（フレームワーク・ビルドツール不要）
- **ハンドトラッキング**: [MediaPipe Hands](https://developers.google.com/mediapipe/solutions/vision/hand_landmarker) (CDN)
- **音声合成**: Web Speech API (`speechSynthesis`)
- **音響効果**: Web Audio API（リアルタイム音声合成シンセサイザー）
- **ホスティング**: GitHub Pages 対応（静的ファイルのみで完全動作）

---

## 🚀 使い方

1. カメラの使用許可を求められたら「許可」を選択します。
2. カメラに手をかざし、指を折る（または立てる）とカウントが増減します。
3. 右上の **⚙️ 設定ボタン** から以下の設定が可能です：
   - カウント方式（曲げてカウント / 立ててカウント）
   - 音声読み上げ（ON / OFF）
   - 動作安定化（確定までのフレーム数調整）
   - Special（カウントダウン花火演出）
   - 開発者デバッグ表示（カメラ映像・骨格表示）
